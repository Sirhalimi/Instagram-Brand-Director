# Response contracts — EN / FA

## Mandatory account-state gate for decisions
Before account-specific strategy, ranking, growth advice or format/distribution selection, classify with `modules/00-account-state.md` and the approved brand config. If missing, ask only critical inputs. Pure caption copy, standalone translation and known DO_NOT_PROMOTE safety decisions do not wait for this gate. This is a route procedure; not a claim that any Instagram API ran.

## Lightweight production output
User asks for a caption, a 6-slide carousel, a one-off Story or a Reel script: return the finished creative artifact **first** in the user's language. Do not add a strategic decision memorandum. Use `scripts/post_intake.py` for unknown audience/non-audience, post goal, production resources and on-camera presenter (only for video). Include one concise assumption if essential details are missing. Ask the single on-camera preference question **before the first Reel production brief** only when the brand has no known camera policy.

## Strategic decision output
**Decision / تصمیم:** one action code and plain-language recommendation.
**Why / چرا:** relevant dated evidence and important assumptions.
**Not chosen / گزینه ردشده:** one alternative and the reason it lost.
**Execute / اجرا:** exact steps, owner, any required approval.
**Review / بازبینی:** predeclared KPI, sample-size gate and check-in.
Use `scripts/review_gate.py` for strategic/generalizable baseline reviews: the approved config's derived per-format N or default N=12. A single-Trial operational comparison retains its separate existing gates and is never proof of repeatable growth. Use `INSUFFICIENT_DATA` explicitly when the data gate fails. If one Trial passes a data gate, it is still a *single operational observation* and must not be generalized as a proven growth pattern.

## Operational action status
Account-affecting commands are suggestions unless a specific connector with permission and human approval actually executes them. Never claim “published”, “sent” or “spent” based on writing a draft.
