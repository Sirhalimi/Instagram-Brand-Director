# Response contracts — EN / FA

## Lightweight production output
User asks for a caption, a 6-slide carousel, a one-off Story or a Reel script: return the finished creative artifact **first** in the user's language. Do not add a strategic decision memorandum. Include one concise assumption if essential details are missing. Ask the single on-camera preference question **before the first Reel production brief** only when the brand has no known camera policy.

## Strategic decision output
**Decision / تصمیم:** one action code and plain-language recommendation.
**Why / چرا:** relevant dated evidence and important assumptions.
**Not chosen / گزینه ردشده:** one alternative and the reason it lost.
**Execute / اجرا:** exact steps, owner, any required approval.
**Review / بازبینی:** predeclared KPI, sample-size gate and check-in.
Use `INSUFFICIENT_DATA` explicitly when the data gate fails. If one Trial passes a data gate, it is still a *single operational observation* and must not be generalized as a proven growth pattern.

## Operational action status
Account-affecting commands are suggestions unless a specific connector with permission and human approval actually executes them. Never claim “published”, “sent” or “spent” based on writing a draft.
