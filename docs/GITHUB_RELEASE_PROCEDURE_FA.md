# وضعیت مهاجرت فایل ZIP قدیمی v0.4

اسکیل از ریشه مخزن به `skills/instagram-brand-director/` منتقل شده است. **اسکریپت قدیمی انتقال ZIP دیگر نباید مستقیماً روی شاخه main اجرا شود**؛ چون می‌تواند `SKILL.md` تکراری در ریشه بسازد و نصب ایزوله را خراب کند.

فایل ZIP قدیمی تنها منبع مقایسه و انتخاب قابلیت‌های مفید است، نه منبع مستقیم جایگزینی فایل‌های جدید. ابتدا در شاخه آزمایشی محتوایش را بررسی، داده‌های خصوصی را حذف و با کد فعلی diff کن. فقط فایل‌های منتخب را همراه منبع، مجوز و تست منتقل کن.

نصب فعلی که در CI بررسی شده:

```bash
npx skills add Sirhalimi/Instagram-Brand-Director --skill instagram-brand-director -a codex -y
```

برای انتشار نسخه‌های بعدی از [چک‌لیست انتشار](RELEASE_CHECKLIST_FA.md) پیروی کن. اتصال Instagram/فروشگاه/انتشار همچنان not-implemented است.
