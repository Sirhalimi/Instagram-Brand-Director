# بررسی خلاقه فارسی و ادغام واقعی ابزارهای آماده

## هدف
در این نسخه برای متن‌های انگلیسی، کدهای واقعی Jake Instagram Agent Skill از پوشه third_party اجرا می‌شوند. برای متن‌هایی که حروف فارسی دارند، ابزار جداگانه بومی‌سازی‌شده فعال می‌شود. امتیازدهی Hook انگلیسی برای فارسی به کار نمی‌رود.

## اجرای ابزار

~~~bash
python3 -m scripts.creative_quality hook --text "۳ اشتباه رایج هنگام خرید کفش"
python3 -m scripts.creative_quality caption --text "این راهنما را ذخیره کن #لباس #مد"
python3 -m scripts.creative_quality hook --text "I lost $240 on this mistake."
python3 -m unittest discover -s tests -v
~~~

## خروجی
- یک اقدام مشخص تحریریه مانند REVISE_HOOK، REVISE_CAPTION یا READY_FOR_HUMAN_REVIEW.
- دلایل اصلاح، تعداد کاراکتر یا واژه، هشتگ‌های تشخیص‌داده‌شده، دسته CTA و تذکر لینک غیرقابل کلیک.
- بدون امتیاز ساختگی کیفیت یا پیش‌بینی Reach برای فارسی؛ همیشه نیازمند بازبینی انسانی.
- دو آستانه \`hook_word_soft_max\` و \`hashtag_policy_max\` صرفاً سیاست قابل‌تنظیم برند هستند و نباید به‌عنوان قانون Meta معرفی شوند.

## وابستگی‌های واردشده
- Social Media Skills: فایل‌های لازم برای شناخت مخاطب، جایگاه‌یابی، لحن و برنامه ساخت ریلز.
- Instagram Skills / sergebulaev: فرمول‌های کپشن، سیاست‌های هشتگ، الگوی Voice و چک‌لیست کپشن.
- Marketing Skills / Corey Haines: شناخت مشتری، استراتژی محصول و اینفلوئنسر مارکتینگ (متن/مرجع؛ اجرای تبلیغ خاموش).
- Apify Ads Intelligence: راهنمای انتخاب Actor برای تحقیق تبلیغات رقبا؛ بدون توکن یا هزینه نمی‌تواند داده دریافت کند.

## محدودیت‌ها
این ابزار تنها کنترل ساختار متن است، نه مدل ارزیابی بازدید. Regex فارسی امکان خطای مثبت و منفی دارد. نتیجه باید با لحن برند و داده واقعی مقایسه شود. اعداد الگوریتم و توصیه‌های فرمولی موجود در مخازن ثالث باید با منابع رسمی به‌روز راستی‌آزمایی شوند.

## مرحله بعد
آزمون با مجموعه نمونه واقعی کپشن/هوک فارسی (با رضایت صاحب برند) و سنجش کیفیت خطاها. اتصال به Brand Profile و گزارش یکپارچه کمپین. ابزارهای تصویر/ویدئو و اجرای تبلیغات همچنان اختیاری‌اند.
